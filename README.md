## 🚀 Featured Projects

### ☀️ SolarWatch — Space Weather Observatory

A space weather monitoring and forecasting project that works with solar X-ray data and GNSS Total Electron Content information.

**What it does**
- Processes live NOAA GOES X-ray flux data.
- Builds hourly features and labels for solar flare forecasting.
- Explores 24-hour M/X-class flare probability prediction.
- Provides a Streamlit dashboard.
- Supports NASA CDDIS GNSS TEC data through Earthdata credentials.

**Built with:** Python · Streamlit · NOAA APIs · NASA CDDIS · Machine Learning

[Explore Repository →](https://github.com/prashil0056/solar-watch)

---

### 🛡️ Possessed Butler — LLM Security Experiment

An adversarial AI attack-and-defense project exploring prompt injection vulnerabilities in LLM-powered agents.

**What it does**
- Generates and mutates adversarial prompt-injection payloads.
- Simulates vulnerable and hardened AI butlers.
- Implements input and output defense layers.
- Uses canary tokens and rule-based breach detection.
- Evaluates attack success and defense performance.

**Built with:** Python · LLMs · Groq API · Prompt Injection · AI Security

[Explore Repository →](https://github.com/prashil0056/possessed-butler)

### 🌕 LUNA-SAFE — Lunar Terrain Hazard Assessment

A research prototype exploring computer vision approaches for identifying boulders and potential terrain hazards in lunar imagery.

**Current implementation**
- Backend API foundation.
- Frontend status dashboard.
- Health-check endpoint.
- Structured data, model and reporting directories.
- Planned lunar image ingestion and hazard-analysis pipeline.

**Built with:** Python · FastAPI · React · Docker · Computer Vision

*Research prototype — the detection and hazard-scoring pipeline is still under development.*

[Explore Repository →](https://github.com/prashil0056/luna-safe)

### ⚙️ Bat2Exe — Batch to Executable

A lightweight utility that packages Windows batch scripts into standalone executable files.

**What it does**
- Embeds batch scripts into a C# executable wrapper.
- Extracts and executes the embedded script.
- Propagates the script's exit code.
- Supports cross-building on macOS and Linux using Mono.

**Built with:** C# · Windows · Mono

[Explore Repository →](https://github.com/prashil0056/bat2exe)
